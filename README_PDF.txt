MoneyMap Statement Manager with PDF Import

Open index.html through a local web server or upload all files to the same website folder. Include index.html, pdf.min.mjs, and pdf.worker.min.mjs.

Supported input: CSV, TXT, and text-based PDF statements. PDF import extracts text locally in the browser using PDF.js. Scanned/image-only PDFs require OCR and will show an error. After import, review dates, signs, balances, transfers, categories, and tax flags because bank layouts vary. No statement content is sent to a server by this application.
